# fd-0005 — Founder Office Determinations: Design System Implementation Unblocked

**Classification: Institutional Record** — determination record
(evidentiary, non-governing).

- **Instrument:** "Huerta Group Design System Reference Implementation —
  Phase 1" task instrument, Founder Office (governing authority) /
  Design System (design authority) → Platform & Systems Development,
  status "Operational Execution Authorized". Incorporates by reference
  the "Founder Office Design System Implementation Authorization" and
  the "Founder Office Determination — Design System Implementation
  Unblocked".
- **Received:** 2026-08-08, as transmitted to the implementing office.
- **Recorded:** 2026-08-08.

## Determinations and operative rules (verbatim from the instrument)

1. Evidence status of the inventory: "Website Phase 1 Inventory is
   approved implementation evidence, not institutional Design System
   authority."
2. Repository support: "Preserve the Website Phase 1 Inventory in its
   approved non-authoritative repository location." · "Establish
   lightweight governed repository locations for: Design Decision
   Records; Governance Recommendations."
3. Decision rules: "When governance does not explicitly determine a
   design decision, make the narrowest responsible implementation
   decision." · "Record material decisions in a lightweight DDR." ·
   "Validate the decision through the website reference
   implementation." · "Continue implementation." · "Do not elevate
   implementation decisions into institutional standards." · "Record
   broader observations as Governance Recommendations."
4. Mechanism status: "Governance Recommendations are non-authoritative."
   · "A Design Decision Record records a Design System decision. It
   does not create authority beyond the decision-making scope granted."
   (per the predecessor instrument's authority rule).
5. Reference-implementation boundary: "Website Development remains the
   Design System reference implementation. Website implementation may
   validate Design System decisions but does not independently create
   Design System authority."
6. Standing constraint: "Do not reopen approved Founder Office
   determinations."

## Effect on recorded deficiencies

The Design System Foundation v1 text remains unpreserved: fd-0001
determination 2 (preservation deferred) and fd-0004 deficiency 6 stand
unchanged. This instrument unblocks Phase 1 implementation through the
decision rules above; it does not supply or reconstruct the deferred
foundation text.

## Affected artifacts

`institution/design/` (design area: inventory preservation, Design
Decision Records, Governance Recommendations); the public website as
reference implementation; the Institutional Evolution Log (trigger
evaluation per existing governance).
