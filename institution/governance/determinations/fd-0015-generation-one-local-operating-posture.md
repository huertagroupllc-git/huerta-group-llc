# fd-0015 — Founder Office Determinations: Generation One Local Operating Posture and Production Cost Deferral

**Classification: Institutional Record** — determination record (evidentiary,
non-governing). The record evidences the determinations; authority resides with
the Founder Office and the artifacts the determinations govern.

- **Instrument:** Generation One Local Operations Activation, execution
  package, Founder Office → Institutional Platform Development.
- **Received:** 2026-08-19.
- **Recorded:** 2026-08-19.
- **Starting baseline:** `54accaa`.
- **Production Supabase expenditure:** **NOT AUTHORIZED.**
- **Current Supabase plan:** Free.
- **Local authentic use:** **AUTHORIZED.**
- **Operating posture:** **LOCAL / PRE-PRODUCTION — AUTHENTIC FOUNDER USE.**

## 1. What this record disposes of

The Production Readiness Report returned three gate decisions and a cost
requirement. The Founder Office has answered the cost question and opened a
narrower path.

- **Production expenditure is not authorized.** The organization is on the Free
  plan and will remain so for now.
- **Production launch remains deferred at the owner/cost gate**, not rejected.
- **Authentic Founder use is authorized in a local pre-production posture**,
  which is new: until now the system held only reproducible fixtures.

## 2. Determinations recorded

1. **Production Supabase expenditure: not authorized.** No paid plan, no paid
   feature, no new recurring infrastructure cost.
2. **Architecture status: unchanged.** The cost deferral is a
   **capital-allocation decision, not a rejection or modification of the
   accepted Generation One architecture.**
3. **ADR-0009 remains controlling.** Generation One must still use its own
   Supabase project if and when production is later authorized.
4. **Prohibition:** Generation One may **not** be placed inside the existing
   public Huerta Group Supabase project merely to remain within Free-tier
   limits. Cost pressure does not dissolve a credential boundary.
5. **Local authentic use is authorized**, classified LOCAL / PRE-PRODUCTION.
   This authorizes authentic operational use by the Founder. It **is not
   production deployment**, authorizes no broader implementation, and does not
   supersede the production isolation requirements of ADR-0009 or any other
   accepted ADR.
6. **Production status: deferred at the owner/cost gate.**

## 3. Return trigger

The production-cost question is not to be reopened during routine local
activation. It returns to the Founder Office when authentic use demonstrates
that persistent hosted availability would materially improve operations, when
local operation becomes materially limiting, or when another significant
circumstance justifies reconsideration.

## 4. What changed materially for Development

The determination that authentic data will now be created locally is the
consequential one. It converts the local database from a disposable fixture
into the only copy of institutional history — which is why the activation work
recorded at the Local Operations Activation Report is principally about
protecting it rather than about convenience.

## 5. Authority boundary

This record evidences determinations; it creates none. Production launch
remains unauthorized. Local authentic use does not expand Generation One scope,
and may not be interpreted as authorization for additional capability.
