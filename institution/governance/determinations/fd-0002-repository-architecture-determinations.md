# fd-0002 — Founder Office Determinations: Proposed Repository Architecture Instrument (D-1…D-8)

**Classification: Institutional Record** — determination record
(evidentiary, non-governing).

- **Instrument:** Repository Foundation Project — Phase 1 — Deliverable
  C (Proposed Repository Architecture) task instrument, Founder Office
  → Platform & Systems Development.
- **Received:** 2026-08-08, as transmitted to the implementing office.
- **Recorded:** 2026-08-08.

## Determinations (verbatim from the instrument)

- **D-1:** "docs/README.md remains a Repository Standard under
  Institutional Repository Governance. Incorporate the corrected
  placement into the proposed architecture only."
- **D-2:** "Repository execution standards shall become model-neutral.
  Escalation authority shall reference Founder Office rather than an
  individual. Identify required standard amendments but do not edit
  standards."
- **D-3:** "Establish a repository staging/workbench architecture
  outside the governed canonical corpus. Working reconstruction
  material shall not reside inside the canonical documentation corpus.
  OSPA recovered canonical documents remain institutionally
  recognized. Missing sections shall not be reconstructed."
- **D-4:** "Repository validation shall ultimately become mechanically
  enforced through CI. Deliverable C shall architect the validation
  framework only. Do not implement CI."
- **D-5:** "Architect repository support for Canonical Source
  Preservation. Do not draft the standard. Define where it belongs and
  its minimum repository function."
- **D-6:** "Institutionally significant governance shall become
  repository-native. Repository execution shall not depend upon AI
  memory."
- **D-7:** "Consolidate duplicated completion and verification
  governance through architecture only. Do not amend standards."
- **D-8:** "CLAUDE.md and AGENTS.md become governed repository
  operational assets. They remain subordinate to institutional
  governance."

## Affected artifacts

The documentation index (D-1); the Bounded Autonomous Completion &
Verification Standard and Development Standards (D-2, D-7 — amendments
executed under the migration instrument, fd-0003); the workbench
(D-3); the validation architecture and CI path (D-4); the
canonical-source-preservation repository standard (D-5); this register
and the repository-operations record (D-6); CLAUDE.md and AGENTS.md
(D-8).
