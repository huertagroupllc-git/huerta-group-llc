# Draft v7 — Validation-Readiness Matrix

**Classification: Institutional Record** — methodology validation record
(evidentiary, non-governing). Produced under `fd-0036`.

**No validation application was performed and none is authorized.** This record
classifies each Draft v7 change by what could legitimately be established about
it **now**, and by what could not. **Nothing below is a validation result.**

**The categories are `fd-0036`'s, used as given:** `MECHANICAL_STRUCTURAL` ·
`PRESERVED_EVIDENCE_REASSESSMENT` · `PARTICIPANT_BEHAVIOR_REQUIRED` ·
`NOT_INTERNALLY_PRODUCIBLE` · `EXTERNAL_APPLICATION_REQUIRED`.

**A standing caveat on every `PRESERVED_EVIDENCE_REASSESSMENT` row.** The
historical applications used **Draft v5 and Draft v6, never Draft v7.** Asking
whether new wording would have addressed a previously observed problem is a
**retrospective structural assessment, not an application of Draft v7**, and is
labelled as such wherever it appears. No prior application is rewritten as
though it had used this version.

## 3. Internal reapplication value — the honest assessment

**Another full internal application against Huerta Group LLC would mainly
repeat already-exercised conditions.** The subject has now been diagnosed under
Draft v6 with participant evidence across two sessions; its A15 capability
instance, its single-participant structure, its uncontested authority and its
records-heavy evidence base are all already exercised. `fd-0036` and the
Founder Office's standing direction forbid manufacturing conditions to change
that.

**Another application against HGP would be weaker still on most items.** HGP has
never supplied participant evidence, sits at the same commit two prior
applications read, and has no A15 capability-plus-decision instance on record.
It could exercise **one** thing the parent cannot: a **different subject**, and
therefore a second reading of the same wording by an applier with a different
evidence base.

**The two items where a narrow internal test could still produce something
genuinely new**, stated precisely:

1. **V7-04's behavioural question** — whether the A20 disclosure prevents the
   aggregate drift. This can only be produced by a **fresh non-authoring
   applier reporting on its own reasoning language**, which is exactly how MD-4
   was detected. It does not need a new subject, a new participant, or a full
   application.
2. **V7-01's two-limb test under an unfamiliar capability instance** — which
   needs a capability-plus-decision condition that is **not** the
   `notification-service` instance already used.

**Everything else on this list is either settled by reading the text or needs a
condition this institution cannot authentically produce.**
