## 2. Coherence

**The set is coherent, and it is coherent in a weaker sense than Stage 7's
seventeen-item set — deliberately.**

- **No item conflicts with another.** Two touch A20 (V6-02, V6-06), both by
  addition to the same list, and both in the same register as CS-13's existing
  entries.
- **Two related items were deliberately merged into one decision.** PC-3(b) and
  PC-4 both raised record-versus-record opposition; it is decided once, in
  **V6-04**, so that A18's mark and Instrument 1's field cannot drift apart —
  which is the failure pattern MF-2 and MF-3 already show between A2 and A18.
- **No item touches A2's architecture.** `fd-0031` §2.4's prohibitions are
  satisfied by construction: nothing in the set introduces evidence strength,
  reliability, credibility, quality, numerical weighting, preferential classes,
  ordering among evidence kinds, or hierarchy through terminology.
- **No item alters methodology semantics beyond an existing determination.**
  Four clarify existing semantics; two are disclosure; one is presentation.
  **The one item that would have changed semantics — PC-7's threshold — was
  removed from the set and reserved.**
- **Six of seven are individually severable.** Only V6-04's absorption of
  PC-3(b) creates a dependency, and it is internal to that item.

**Revalidation profile of the whole set:** **three items require no fresh
validation** (V6-01, V6-02, V6-06(a)); **four require targeted revalidation**
(V6-03, V6-04, V6-05, V6-06(b), V6-07). **None requires external validation to
test.** One — V6-05 — requires an application with at least one session, and one
— V6-04 — cannot be fully tested without participant access.

## 3. Whether this justifies Draft v6 construction

**The change set is coherent and its authority is settled, with one reserved
question that does not block it.**

- All seven findings are accepted; five proposals are narrowed and two accepted
  as written; nothing is left ambiguous within the set.
- **RQ-1 is severable** — V6-07 carries the recording limb only, and setting a
  threshold later would not disturb it.
- **RQ-2 is not in the set at all** — V6-02 is disclosure, and the structural
  question is reserved without blocking the disclosure.

**But `fd-0031` §2.12 requires the reserved questions returned first, and this
record does not treat the method as determinate while they stand.** The
recommendation is therefore conditional, and it is stated as such in the Stage
11 report: **Draft v6 construction is warranted once RQ-1 is either answered or
expressly excluded from the drafting scope.** Nothing here recommends beginning
it.

## 4. What this change set does not do, and must not be read as doing

**It does not close the participant-facing validation gap, and no item in it
could.** Five of seventeen consolidation items remain partially exercised —
four of them for want of a participant, one because its unexercised branch
cannot be produced internally without manufacturing it. **That is an absence of
validation evidence, not a method defect** (`fd-0031` §2.8), and **converting it
into drafting work would disguise it**, which `fd-0031` §2.12 expressly forbids.

**After Draft v6, the outstanding need is unchanged: an application with
participant access.** The method's people-facing procedures — A10's observation
limb, A7's habit test, A6's role compression, A9's first three source roles, A3
step 8's clarification-only follow-up — have never been exercised in any version,
and this change set does not touch them.
