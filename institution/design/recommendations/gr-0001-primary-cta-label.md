# gr-0001 — Primary CTA Label Duality

**Classification: Institutional Record** — Governance Recommendation
(non-authoritative; fd-0005). Date: 2026-08-08.

The primary contact action carries two labels across the site — "Start
a conversation" (home hero, header CTA, about band) and "Contact
Huerta Group" (remaining heroes and bands). This is voice/copy, not
component architecture, so Phase 1 preserves both verbatim.
**Recommendation:** Branding (with Design System) determine whether one
label, or a deliberate two-label rule, governs the primary action.
