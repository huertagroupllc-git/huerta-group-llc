# gr-0002 — Semantic Status Color Layer

**Classification: Institutional Record** — Governance Recommendation
(non-authoritative; fd-0005). Date: 2026-08-08.

Gold currently serves as both the accent and the error color (form
error banner and field errors render in accent gold). Contrast passes
and Phase 1 retains it unchanged. **Recommendation:** before any
richer feedback UI (dashboards, portals, richer forms), Design System
with Branding decide whether the palette gains a semantic
status layer (error/success/warning) distinct from brand gold, or
whether gold-as-status is institutional intent.
