## Status of this record

This is the single canonical repository record of Methodology
Foundation v1 and the authoritative source from which the eight initial
Method Library records derive. It preserves, accurately and without
embellishment, the approved content transmitted with the implementing
authorization: the foundation's structure, controlled vocabularies,
lifecycle and authority rules, disclosure model, record definitions,
technical boundaries, and unresolved matters.

**The complete approved prose of the foundation's numbered sections
(notably §§1.1–1.3 institutional-methodology definition text and the §2
five-layer architecture text) was not transmitted with the implementing
authorization and is therefore not reproduced here.** Following the
repository's constitutional-record convention, that text must be
inserted **verbatim** through Methodology authority when supplied —
never reconstructed, paraphrased, or inferred (and never inferred from
the public Methodology page, which is public positioning, not internal
methodology). The absence of the full sectional text does not diminish
the approved status of what is recorded below.

## 6. Authority, versioning, and supersession (§6)

- **Interim approval rule:** methodological approval currently rests on
  the Founder's existing institutional authority. This rule is
  **interim and configurable**: it is subordinate to the Constitution
  and to any later-approved decision-rights architecture, and no
  technical artifact may encode it as immutable. No technical role,
  file permission, or repository access constitutes institutional
  approval.
- **Corrections and refinements:** non-substantive corrections
  (spelling, formatting, broken references, metadata errors, clerical
  inconsistencies) do not create a new substantive version. Substantive
  changes — to meaning, scope, requirements, methodological logic,
  decision criteria, required evidence, approved application,
  limitations, or disclosure boundaries — require a new version and
  Methodology approval.
- **Supersession:** superseded records are never deleted; they are
  retained with status `superseded`, linked to their replacement, with
  git history as the version record.
- **Disagreement and uncertainty:** open questions, disagreements, and
  uncertainty are recorded on the affected records rather than hidden
  or silently resolved.

Derived record: `mr-0007`.

## 9. Technical implementation boundaries

The Method Library foundation is a repository-based institutional
record system: file-based, version-controlled, deterministic,
reversible. It authorizes **no** runtime application, database,
authentication, administrative interface, search or retrieval service,
AI system, workflow automation, scoring, or public publication.
